# github-oidc-exchange v0.7.3

## Summary

Version 0.7.3 is a patch release for Kubernetes portability, deterministic
configuration rollout, and operator-facing release artifacts. It preserves
Identity's public routes, audiences, policy schemas, two-minute token lifetime,
and default `steward-task-v2` behavior.

The chart now permits Kubernetes API-server egress on TCP 443 and 6443 across
IPv4 and IPv6, with explicit NodeLocal DNSCache and additional proxy-egress
controls. A Kubernetes 1.36 regression proves Lease traffic reaches the API
server after Service DNAT.

Projected ConfigMaps and Secrets still load only at process startup. The chart
keeps explicit rollout revisions as its controller-free default and adds an
opt-in named-resource integration for an operator-managed Stakater Reloader.
The release also ships `/usr/local/bin/keyring-tool` in the signed image,
attaches policy schemas and examples, and publishes maintained Artifact Hub
repository metadata.

The installation, integration, and upgrade guides correct the pinned
steward-run workflow, Steward workload-exchange namespace, discovery field
names, Helm release name, v6 activation and rollback pairing, and signing-key
rotation sequence.

## Compatibility and activation

| Application/chart | Policy | Output | Activation |
| --- | --- | --- | --- |
| 0.7.3 / 0.7.3 | v5 | `steward-task-v2` | Default; continues to issue the unchanged token contract |
| 0.7.3 / 0.7.3 | v6 | `steward-task-v3` | Explicit values plus separate policy object |
| 0.7.2 / 0.7.2 | v5 or v6 | v2 or v3 | Historical rollback pair; same runtime token contracts |

Policy `github-oidc-exchange.apelogic.io/v5` remains the chart default. Policy
`github-oidc-exchange.apelogic.io/v6` remains an explicit opt-in. Discovery
continues to advertise `github_oidc_audience`,
`identity_contracts_supported`, and `policy_versions_supported` alongside the
exact exchange endpoint.

Follow the [0.7.3 upgrade guide](../upgrade-v0.7.3.md). Preserve the complete
application/chart and policy pairing during activation and atomic rollback.

## Release evidence

`release-manifest.json` contains the source commit, workflow run, immutable
public image and chart coordinates, native amd64 and arm64 container platform
digests, and supported contract identifiers. It contains no `ecr_*` fields or
private-registry coordinates. The public GitHub release assets no longer contain private-registry
descriptors or raw internal scan inputs.

The release also attaches the packaged chart, policy schemas and examples,
platform descriptors, signature bundles, and the Artifact Hub repository
verification artifact. Verify the handoff with `cosign verify-blob`. Verify
public OCI signatures and the SPDX SBOM and SLSA provenance attestations with
`cosign verify` and `cosign verify-attestation`. `image.digest` must come from
the verified release handoff or a verified manifest-preserving mirror;
tag-only production deployment is unsupported.
