# github-oidc-exchange v0.7.6

## Summary

Version 0.7.6 adds optional generic OIDC exchange, pure-service task tokens
for exact Kubernetes workload identities, and two explicitly selected chart
delivery modes. It also updates the certificate-validation dependencies and
bundled trust roots to reject paths through distrusted emSign intermediates.

The generic OIDC profile is disabled by default. When enabled, it accepts only
administrator-configured HTTPS issuers, exact audiences, RS256 assertions, and
non-overlapping exact claim bindings. It emits ES256 `steward-task-v2` tokens
from the policy-bound service and owner; requests cannot select identity.
Source assertions are single-use through a bounded `jti`, or through the
documented Jenkins `build_number` replay identity when no `jti` is present.
Each provider refreshes independently, so one unavailable provider does not
disable GitHub exchange or another ready provider.

Generic OIDC discovery and JWKS may optionally add public certificates from a
dedicated CA Secret. The file is rejected when it is unreadable,
certificate-free, invalid, or contains private-key material. Its trust is
scoped to generic OIDC; GitHub, Kubernetes, and workload clients keep their
existing roots.

An exact workload-policy identity may now use a `task` binding instead of
OpenShell roles. That binding issues a replay-protected, pure-service ES256
`steward-task-v2` token with fixed audience and policy-bound owner. Existing
role bindings continue to issue their unchanged RS256
`openshell-workload-v1` tokens.

The chart still requires an immutable image digest by default and still
references an external GitHub policy ConfigMap by default. Operators may
explicitly select tag-only rendering when their delivery platform owns tag
immutability, or chart-owned rendering of validated public v5/v6 policy data.
Neither opt-in permits signing keys, TLS private keys, registry credentials,
or other secret material in values.

## Compatibility and activation

| Application/chart | Policy | Output | Activation |
| --- | --- | --- | --- |
| 0.7.6 / 0.7.6 | `github-oidc-exchange.apelogic.io/v5` | `steward-task-v2` | Default; unchanged behavior |
| 0.7.6 / 0.7.6 | `github-oidc-exchange.apelogic.io/v6` | `steward-task-v3` | Explicit policy selection |
| 0.7.5 / 0.7.5 | v5 or v6 | matching v2 or v3 | Supported rollback pair |

No existing value becomes required, and no existing optional profile becomes
enabled. Public OCI coordinates, signer identity, release signature filenames,
GitHub policy versions, token lifetimes, and the Kubernetes floor are
unchanged. Follow the [0.7.6 upgrade guide](../upgrade-v0.7.6.md).

## Release evidence

Verify `release-manifest.json` and its
`release-manifest.sigstore.json` bundle, then verify the exact image and chart
digests plus their signatures and SPDX/SLSA attestations. The release retains
`public-image-signature.sigstore.json` and
`public-chart-signature.sigstore.json`.
