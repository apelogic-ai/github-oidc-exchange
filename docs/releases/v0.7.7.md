# github-oidc-exchange v0.7.7

## Summary

Version 0.7.7 adds one default-off chart option: chart-owned rendering of the
workload-policy ConfigMap. The application, routes, audiences, token lifetimes,
policy versions, and output contracts are unchanged.

By default the chart still references an operator-managed workload-policy
ConfigMap. Platforms that can supply Helm values but cannot apply a separate
policy manifest may enable the new workload-policy `create` value and put the
validated public policy object in its `document` value. The
chart then creates the configured workload-policy ConfigMap under the
configured key, validates the document against the workload policy schema, and
includes its content in the Deployment checksum so a policy change rolls the
pods. The workload RSA keyring, TLS private key, and other secret material
remain external and are never accepted in values. The
[0.7.7 upgrade guide](../upgrade-v0.7.7.md) gives the exact value names.

## Compatibility and activation

| Application/chart | Policy | Output | Activation |
| --- | --- | --- | --- |
| 0.7.7 / 0.7.7 | `github-oidc-exchange.apelogic.io/v5` | `steward-task-v2` | Default; unchanged behavior |
| 0.7.7 / 0.7.7 | `github-oidc-exchange.apelogic.io/v6` | `steward-task-v3` | Explicit policy selection |
| 0.7.6 / 0.7.6 | v5 or v6 | matching v2 or v3 | Supported rollback pair |

No existing value becomes required, and no existing optional profile becomes
enabled. With the new option left off, the rendered manifests match 0.7.6
apart from version labels. Public OCI coordinates, signer identity,
release signature filenames, GitHub policy versions, token lifetimes, and the
Kubernetes floor are unchanged. Follow the
[0.7.7 upgrade guide](../upgrade-v0.7.7.md).

## Release evidence

Verify `release-manifest.json` and its
`release-manifest.sigstore.json` bundle, then verify the exact image and chart
digests plus their signatures and SPDX/SLSA attestations. The release retains
`public-image-signature.sigstore.json` and
`public-chart-signature.sigstore.json`.
