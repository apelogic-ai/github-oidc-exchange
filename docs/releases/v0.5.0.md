# github-oidc-exchange v0.5.0

This release removes the obsolete Steward Service Envelope bootstrap identity
profile so a dormant privileged path cannot be accidentally reactivated.
GitHub exchange now requires the task-only policy contract
`github-oidc-exchange.apelogic.io/v5`.

Normal governed-task behavior is unchanged: successful exchanges still emit
the service-principal, verified acting-user, and opaque canonical-user groups;
the fixed `steward-task-api` audience, `steward-task-v2` identity contract,
two-minute lifetime, source provenance, replay protection, signing, workload
exchange, and browser HOP-1 contracts remain intact.

## Required migration

1. Remove top-level `bootstrap_group`.
2. Remove `profile`, `workflow_refs`, and `job_workflow_refs` from repository
   rules, and delete bootstrap-only rules.
3. Set `version` to `github-oidc-exchange.apelogic.io/v5` while retaining all
   reviewed task selectors and actor mappings.
4. Create a separate v5 ConfigMap, then deploy application/chart 0.5.0 and
   switch the policy ConfigMap reference in the same Helm revision.
5. Verify readiness, discovery/JWKS, one admitted task, all negative selector
   cases, and replay denial.

Application 0.5.0 rejects v4 with `unsupported policy version`. Rollback is
the complete 0.4.0 application/chart plus v4 policy pair; rolling back only the
image while retaining v5 is unsupported. See the complete
[upgrade guide](https://github.com/apelogic-ai/github-oidc-exchange/blob/v0.5.0/docs/upgrade-v0.5.0.md).

## Release evidence

The release workflow passed Rust formatting, linting, tests, policy/schema and
documentation drift checks, Helm validation, native amd64 and arm64 container
smokes, chart and image vulnerability scans, public exact-digest pull checks,
and signature, SPDX SBOM, and SLSA provenance verification. Exact public GHCR
and private ECR image/chart coordinates, per-platform image digests, source
commit, policy contract, and identity contract are in the signed
`release-manifest.json` attached to this release.

Download and verify the handoff with GitHub CLI, `jq`, `oras`, and Cosign 3.1.2
or newer:

```sh
export RELEASE_REPOSITORY=apelogic-ai/github-oidc-exchange
export RELEASE_VERSION=v0.5.0
export RELEASE_IDENTITY=https://github.com/apelogic-ai/github-oidc-exchange/.github/workflows/release.yml@refs/heads/main
export RELEASE_OIDC_ISSUER=https://token.actions.githubusercontent.com
export RELEASE_EVIDENCE_DIR="$(mktemp -d)"
gh release download "$RELEASE_VERSION" --repo "$RELEASE_REPOSITORY" \
  --dir "$RELEASE_EVIDENCE_DIR"
cd "$RELEASE_EVIDENCE_DIR"

cosign verify-blob \
  --bundle release-manifest.sigstore.json \
  --certificate-identity "$RELEASE_IDENTITY" \
  --certificate-oidc-issuer "$RELEASE_OIDC_ISSUER" \
  release-manifest.json

jq -e '
  . as $m
  | .version == "0.5.0"
    and (.commit | test("^[0-9a-f]{40}$"))
    and (.release_url | endswith("/releases/tag/v0.5.0"))
    and (.workflow_run_url | test("/actions/runs/[0-9]+$"))
    and .policy_contract == "github-oidc-exchange.apelogic.io/v5"
    and .identity_contract == "steward-task-v2"
    and (.public_image_digest | test("^sha256:[0-9a-f]{64}$"))
    and (.public_chart_digest | test("^sha256:[0-9a-f]{64}$"))
    and (.ecr_image_digest | test("^sha256:[0-9a-f]{64}$"))
    and (.ecr_chart_digest | test("^sha256:[0-9a-f]{64}$"))
    and ($m.image | endswith("@" + $m.public_image_digest))
    and ($m.chart | endswith("@" + $m.public_chart_digest))
    and ($m.ecr_image | endswith("@" + $m.ecr_image_digest))
    and ($m.ecr_chart | endswith("@" + $m.ecr_chart_digest))
    and (.image_platforms.linux.amd64 | test("^sha256:[0-9a-f]{64}$"))
    and (.image_platforms.linux.arm64 | test("^sha256:[0-9a-f]{64}$"))
' release-manifest.json >/dev/null

for field in image chart; do
  reference="$(jq -r --arg field "$field" '.[$field]' release-manifest.json)"
  digest="${reference##*@}"
  oras manifest fetch --descriptor "$reference" | jq -e --arg digest "$digest" \
    '.digest == $digest' >/dev/null
  cosign verify --certificate-identity "$RELEASE_IDENTITY" \
    --certificate-oidc-issuer "$RELEASE_OIDC_ISSUER" \
    --experimental-oci11=true --new-bundle-format=true "$reference" >/dev/null
  cosign verify-attestation --certificate-identity "$RELEASE_IDENTITY" \
    --certificate-oidc-issuer "$RELEASE_OIDC_ISSUER" \
    --experimental-oci11=true --new-bundle-format=true \
    --type spdxjson "$reference" >/dev/null
  cosign verify-attestation --certificate-identity "$RELEASE_IDENTITY" \
    --certificate-oidc-issuer "$RELEASE_OIDC_ISSUER" \
    --experimental-oci11=true --new-bundle-format=true \
    --type slsaprovenance1 "$reference" >/dev/null
done
```

The public `image` and `chart` references above are anonymously pullable.
After authenticating to the release ECR registry, repeat the same Cosign
signature and two attestation checks for the manifest's `ecr_image` and
`ecr_chart` references. The v0.4.0 rollback coordinates are in that release's
signed manifest; restore those application/chart coordinates together with the
retained v4 policy ConfigMap.
